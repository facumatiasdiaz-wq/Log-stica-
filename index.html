Control de Pedidos y Retiros

Cargá cada pedido y cada retiro a mano. El pendiente por producto (pedido acumulado menos retirado) se calcula solo. Los datos se guardan en una planilla de Google Sheets.

No se pudo conectar con la planilla. Revisá que el link del Apps Script en config.js esté bien puesto y que el despliegue tenga acceso "Cualquier usuario".

Cargar movimiento

Elegí si es un pedido nuevo o un retiro, cargá el producto y la cantidad. El producto podés tipearlo o elegirlo de la lista de productos habituales.

Cualquiera puede ver los datos, pero para cargar o borrar movimientos hace falta el PIN.

Pedidos abiertos

Un pedido aparece acá mientras tenga unidades sin retirar. Cuando el retirado alcanza al pedido, se cierra y desaparece solo de esta lista.
